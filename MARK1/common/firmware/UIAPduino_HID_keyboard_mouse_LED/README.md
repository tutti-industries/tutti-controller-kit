# HID キーボード・マウス + 待機LED演出

UIAPduino Pro Micro CH32V003 V1.4 用の統合ファームです。

- 起動後、USB HIDとしてPCに認識されながらLED演出を繰り返します。
- マトリクスキーのいずれかを押すと、待機演出を直ちに停止します。
- ジョイスティック操作は待機演出の終了条件に使いません。ジョイスティック回路が未実装でも、ADCピンの浮遊値に影響されずLED演出を継続します。
- 操作を検出した同じループでHID入力を送るため、最初のキー操作は捨てません。
- 以降は通常のキーボード・マウス動作と、キー種別に応じたLED表示になります。
- ACアダプタ給電時も待機演出は動作します。PCは不要です。

## ビルド

通常は1つ上のフォルダにある `build.bat` を実行します。

このフォルダから直接ビルドする場合は次を実行します。

```text
make clean && make build
```

## 書き込み

1つ上の `flash.bat` を実行し、画面の指示に従ってUSBを挿し直してください。

## 編集箇所

キーマップ、行列ピン、LEDピン、ジョイスティック感度は
`demo_hid_keyboard_mouse_led.cpp` 冒頭の定義を編集します。

このプロジェクトは `MARK1/common/firmware` 内の `vendor` と `shared` にある
USB/HIDスタックを参照します。STAGE1〜4のfirmwareフォルダには依存しません。
